Подключение

Аккаунт Anime 365 и доступ к медиасерверу.

Нужна активная премиум-подписка. Проверка сайта не проверяет логин и пароль.

Медиасервер

Для существующей медиатеки используйте прежний сервер. Переключение библиотеки между Emby и Jellyfin не поддерживается.

Настройки Emby
Адрес, доступный контейнеру sidecar. Для Emby из Epsilon оставьте значение по умолчанию.
Создайте ключ в панели администратора медиасервера.
Параметр parentId в адресе страницы библиотеки.
ID в адресе страницы пользователя в разделе Users.
Если пусто, используется внутренний адрес. Укажите адрес, доступный с вашего устройства. Ссылки ведут в /web/index.html от корня адреса.
Настройки Jellyfin
Адрес с префиксом пути, если он есть. Например, http://jellyfin:8096/jellyfin. Не добавляйте /web.
Создайте ключ в панели администратора медиасервера.
UUID библиотеки, с дефисами или без них.
UUID пользователя в адресе страницы его настроек.
Если пусто, используется внутренний адрес. Укажите адрес, доступный с вашего устройства. Префикс пути сохраняется; не добавляйте /web.
Папка в медиасервере/downloads/anime365Подключите общую папку Umbrel downloads/anime365 к библиотеке типа «Сериалы». У Jellyfin должен быть ровно один путь в библиотеке.

Загрузка

Какие сериалы и версии серий сохранять.

list_watching — «Смотрю», list_planned — «Запланировано». Можно добавить ID тайтлов через запятую.
Через запятую: ru_subtitles, ru_dub, ja_raw. Каждый перевод занимает место как отдельное видео.
Названия команд или имена авторов через запятую. Если подходящего перевода от них нет, загружаются все подходящие переводы.
Полные имена без скобок, через запятую. Регистр не важен. Исключения имеют приоритет над предпочтениями.
Относительно последней просмотренной серии в Anime 365. По умолчанию — 50.
Поиск серий, синхронизация списков и просмотров, очистка. По умолчанию — 5m.

Очистка

По умолчанию загруженные серии остаются в медиатеке.

С последнего воспроизведения на медиасервере. 336h — две недели; 0s — без задержки. Если сервер не сообщает время просмотра, задержка не применяется.

Уведомления

Сообщения от sidecar в Telegram.

Формат: telegram://токен@api.telegram.org/?recipient=chat_id. Боту нужны права на отправку сообщений в этот чат.

Уведомления о загруженных переводах и удалении недоступных переводов непросмотренных серий. Адрес медиасервера для ссылок задаётся в разделе «Подключение».

Дополнительно

Интервалы, внешние каталоги и сеть.

Интервалы указываются в формате Go: 30s, 5m, 1h30m. Для суток используйте часы: 24h.

Прокси

Прокси используется стандартными HTTP-клиентами Go. Многопоточная загрузка видео его не учитывает: эти настройки не направляют весь трафик через прокси.

Имена и IP-адреса без прокси, через запятую. Добавьте адрес вашего медиасервера.

Каталоги контейнера

Пути заданы пакетом Umbrel. Для их изменения нужны соответствующие тома в Docker Compose.

В пакете используется tmpfs: доступное место зависит от памяти устройства.
