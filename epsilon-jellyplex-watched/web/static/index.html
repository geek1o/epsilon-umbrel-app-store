Твои серверы

Для синхронизации нужны хотя бы два сервера. Можно добавить несколько серверов одного типа.

↔

Начни с двух серверов

Добавь Plex, Jellyfin или Emby и укажи API-токен.
Проверь доступ перед первым запуском.

Где взять токен

Jellyfin / Emby: Панель управления → Дополнительно → API-ключи. Создай ключ для JellyPlex-Watched.

Plex: используй X-Plex-Token администратора ↗.

Для Emby из магазина Epsilon можно использовать внутренний адрес http://epsilon-emby_server_1:8096/emby. При доступе по IP Umbrel внешний порт Emby — 8098. Для Plex и Jellyfin укажи адрес, доступный из приложения, а не localhost.

Как синхронизировать

Изменения настроек применяются со следующего запуска. Текущий запуск завершится со своими настройками.

Режим и расписание

Направления

Строка — источник, столбец — получатель. Направление действует на все серверы выбранного типа. Для обмена в обе стороны включи оба направления.

Дополнительные параметры

Пользователи и библиотеки

Без фильтров участвуют все совпадающие пользователи и библиотеки. Настрой соответствия, если имена различаются.

Имена пользователей

JSON из пар имён. Например: {"alice": "Алиса"}. Соответствие работает в обе стороны.

Названия библиотек

JSON из пар названий. Например: {"Movies": "Фильмы"}. Не добавляй одно имя в несколько пар.

Кто участвует в синхронизации

Перечисли имена через запятую. Пустой разрешающий список означает «все». Запреты и сопоставления обрабатывает JellyPlex-Watched.
