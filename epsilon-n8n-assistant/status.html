n8n Assistant Sandbox — configuration

This app runs the self-hosted sandbox provider and bundled web search (SearXNG) for the n8n app from the official Umbrel App Store, following n8n's guide “Set up n8n Assistant” — Setup 2: Self-host the sandbox manually.

1. Verify the sandbox is healthy

From the n8n app container (e.g. via the n8n app's shell or a Execute Command node):

wget -qO- http://epsilon-n8n-assistant_sandbox-api_1:8080/healthz
# expected: {"status":"ok"}

2. Configure n8n

Set these environment variables for the n8n instance:

N8N_INSTANCE_AI_SANDBOX_ENABLED=true
N8N_INSTANCE_AI_SANDBOX_PROVIDER=n8n-sandbox
N8N_SANDBOX_SERVICE_URL=http://epsilon-n8n-assistant_sandbox-api_1:8080
N8N_SANDBOX_SERVICE_API_KEY=9546cf40f33b0153607d4a806086981447c09f1cef8a3f23
N8N_INSTANCE_AI_SEARXNG_URL=http://epsilon-n8n-assistant_searxng_1:8080

3. Enable the Assistant

Add a model API key (Anthropic, OpenAI or OpenRouter) in the n8n editor's AI settings, or via N8N_INSTANCE_AI_MODEL_API_KEY. Optionally set a Brave Search key (INSTANCE_AI_BRAVE_SEARCH_API_KEY) — it takes priority over the bundled SearXNG.

Stack: n8n sandbox service 1.3.4 (API, runner and sandbox images ship as one release). Intended for development and testing; for production n8n recommends the managed Daytona sandbox provider.
